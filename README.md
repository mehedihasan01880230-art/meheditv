# MEHEDI X NETSCOPE — Live TV

Netscope ব্রডব্যান্ড গ্রাহকদের জন্য লাইভ টিভি ওয়েবসাইট (React + Vite + Tailwind CSS)।
মোবাইল ও পিসি — দুই জায়গাতেই সুন্দরভাবে চলে।

## ফিচার
- M3U প্লেলিস্ট থেকে নিজে নিজে চ্যানেল লোড (GitHub-এ ফাইল আপডেট করলেই সাইটে নতুন চ্যানেল)
- সার্চ, ক্যাটাগরি (সংবাদ / বিনোদন / খেলাধুলা / ইসলামিক / কিডস), প্রিয় চ্যানেল (❤️)
- শেষ দেখা চ্যানেল মনে রাখে, আগের/পরের চ্যানেল বাটন
- HLS (.m3u8) ও .ts স্ট্রিম সাপোর্ট, এরর হলে "আবার চেষ্টা করুন"

## লোকালি চালানো
```bash
npm install
npm run dev      # ডেভেলপমেন্ট
npm run build    # dist/index.html তৈরি হবে
```

## GitHub Pages-এ চালু করা
1. প্রজেক্টটি GitHub রিপোজিটরিতে `main` ব্রাঞ্চে push করুন।
2. Repository → **Settings → Pages → Source = GitHub Actions** সিলেক্ট করুন।
3. প্রতিবার push করলে `.github/workflows/deploy.yml` নিজে থেকেই বিল্ড করে সাইট প্রকাশ করবে।

## সেটিংস
`src/config.ts` ফাইলে টাইটেল, সাবটাইটেল ও প্লেলিস্টের লিংক বদলানো যাবে।

## জরুরি নোট
GitHub Pages `https` ব্যবহার করে। তাই প্লেলিস্টের যেসব স্ট্রিম লিংক শুধু `http://` সমর্থন করে
(ব্রাউজার "Mixed Content" ব্লক করে) সেগুলো Pages-এ নাও চলতে পারে। সাইট নিজে `https` চেষ্টা করে,
কিন্তু সার্ভার সমর্থন না করলে চলবে না। এগুলো চালাতে চাইলে `https` লিংক ব্যবহার করুন,
অথবা সাইটটি `http://` সার্ভারে হোস্ট করুন।
